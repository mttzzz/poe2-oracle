# PoE2 Oracle

![The PoE2 Oracle price panel, a currency's market card and the XP overlay's line](images/en/hero.webp)

## English

PoE2 Oracle is a free Windows overlay for Path of Exile 2: point at an item, press
<kbd>Ctrl</kbd>+<kbd>E</kbd>, and see what it sells for.
**[Read the guide in English](en/introduction.md)**.

## Русский

PoE2 Oracle — бесплатный оверлей для Path of Exile 2 под Windows: наведите курсор на предмет,
нажмите <kbd>Ctrl</kbd>+<kbd>E</kbd> — и узнаете, за сколько он продаётся.
**[Читать руководство на русском](ru/introduction.md)**.
