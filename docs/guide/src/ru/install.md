# Установка и первый запуск

## Что нужно

- Windows 10 или Windows 11, 64-битная. Больше ничего ставить заранее не нужно: ни .NET, ни
  распространяемый пакет Visual C++ программе не нужны. Только для необязательного входа на
  pathofexile.com нужен Microsoft Edge WebView2 Runtime; если его нет, настройки скажут об этом и
  предложат «Скачать с сайта Microsoft».
- Path of Exile 2 с русским или английским клиентом.
- Режим экрана игры **«Оконный»** или **«Оконный полноэкранный»**. Поверх режима «Полноэкранный»
  Windows не показывает окна других программ, и панель не будет видна.
- Интернет: цены берутся с сайта торговли Path of Exile, из данных валютной биржи GGG
  (`web.poecdn.com`) и с poe2scout.

## Скачать

На [oracle.pushka.biz](https://oracle.pushka.biz/ru/) нажмите «Скачать для Windows» — кнопка
всегда скачивает последнюю версию установщика, `PoE2-Oracle-Setup-<версия>.exe`.

У каждого выпуска на сайте есть и файл `SHA256SUMS` — по адресу
`https://oracle.pushka.biz/download/v<версия>/SHA256SUMS`, для версии 0.1.0 это
<https://oracle.pushka.biz/download/v0.1.0/SHA256SUMS>. Чтобы проверить загрузку, выполните в
PowerShell в папке с установщиком команду ниже и сравните результат со строкой установщика в
`SHA256SUMS` (регистр букв не важен):

```powershell
Get-FileHash .\PoE2-Oracle-Setup-*.exe -Algorithm SHA256
```

## SmartScreen

Установщик пока не подписан цифровой подписью, поэтому при запуске Windows может написать
«Система Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом
случае**. Браузер тоже может предупредить, что файл скачивают редко, — сохраните его.

## Установка

- Установщик говорит по-русски или по-английски — в зависимости от языка Windows.
- Программа ставится только для вашего пользователя Windows, права администратора не нужны. Папка
  по умолчанию — `%LOCALAPPDATA%\Programs\PoE2 Oracle`, можно выбрать другую.
- В меню «Пуск» появляется ярлык **PoE2 Oracle**. Ярлыка на рабочем столе нет.
- На последней странице можно сразу запустить PoE2 Oracle и включить «Запускать вместе с Windows».
  Эта галочка отмечена, если в автозагрузке Windows есть запись PoE2 Oracle, даже отключённая в
  диспетчере задач; отмеченная галочка включает автозапуск, снятая — выключает.
- Если PoE2 Oracle уже запущен, установщик предупредит: «PoE2 Oracle запущен и будет закрыт, чтобы
  продолжить.» — и закроет его.

## Режим экрана игры

В настройках графики игры выберите режим **«Оконный полноэкранный»** (или «Оконный»). Если игра в
режиме «Полноэкранный», окно настроек PoE2 Oracle предупредит об этом вверху.

## Первый запуск

Главного окна у PoE2 Oracle нет. Программа работает в фоне, и видно её только по значку в области
уведомлений у часов. Если значка не видно, он может прятаться под стрелкой **^** («Показать скрытые
значки»); его можно перетащить на панель задач. Наведите на значок — подсказка покажет горячую
клавишу: «PoE2 Oracle — проверка цены: Ctrl+E».

При самом первом запуске программа несколько секунд загружает данные сайта торговли, а затем
проводит короткое обучение. Оно затемняет экран вокруг одного места за раз и объясняет его на
карточке: лигу в окне настроек; затем в игре нужно навести курсор на предмет и нажать
<kbd>Ctrl</kbd>+<kbd>E</kbd>; затем фильтры, «Поиск», лоты и лигу на открывшейся панели цены; и
напоследок оверлей опыта. «Далее» и «Назад» переходят между шагами, а шаг, который ждёт вас, —
например, первая проверка цены — сам идёт дальше, когда вы это сделаете. «Пропустить обучение»
заканчивает его. Обучение запускается при каждом старте программы, пока вы его не пройдёте или не
пропустите; после этого его можно пройти заново в настройках: «Помощь» → «Обучение» → «Пройти
заново».

PoE2 Oracle говорит по-русски и по-английски. Сначала программа следует языку клиента игры, а пока
игра ни разу не запускалась, — языку Windows; сменить язык можно в настройках, строка «Язык
интерфейса». См. [Язык интерфейса](settings.md#язык-интерфейса).

Просмотрите [настройки](settings.md): главные из них — лига, язык клиента, язык интерфейса и
горячая клавиша.
Изменения применяются и сохраняются сразу. Предупреждения со значком **⚠** вверху окна значат, что
что-то мешает проверке цены; см. [Решение проблем](troubleshooting.md).

Теперь в игре наведите курсор на предмет и нажмите <kbd>Ctrl</kbd>+<kbd>E</kbd>. Подробнее — в
разделе [Проверка цены](price-check.md).

## Значок в трее

Щёлкните по значку (правой кнопкой тоже можно), чтобы открыть меню:

- «Настройки» — открывает [настройки](settings.md);
- «Проверить обновления» — ищет новую версию; см. [Обновления и удаление](updates.md);
- «Сообщить о проблеме или идее…» — открывает [окно сообщения разработчику](report.md);
- «Выход» — закрывает PoE2 Oracle.

## Одна копия

Одновременно работает только одна копия PoE2 Oracle. Повторный запуск, например из меню «Пуск»,
открывает настройки уже работающей копии. Копия, запущенная вместе с Windows, когда другая уже
работает, тихо завершается.

## Автозапуск

Включите «Запускать вместе с Windows» в разделе «Общие» настроек или отметьте галочку на последней
странице установщика. Запущенный вместе с Windows, PoE2 Oracle ждёт в трее, пока вы не начнёте
играть. Исключений два: пока обучение не пройдено и не пропущено, оно открывается при каждом
запуске, а первый запуск после вылета открывает
[окно сообщения разработчику](report.md#после-вылета).
