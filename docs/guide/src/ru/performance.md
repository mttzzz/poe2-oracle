# Производительность

PoE2 Oracle — нативная программа для Windows, написанная на Rust: один процесс, без Electron и без
браузера внутри, а интерфейс рисует видеокарта. Здесь собраны замеры, на которых стоят числа
[сайта](../../ru/): PoE2 Oracle рядом с другими программами проверки цен в игре и пока игра в фоне,
её собственная скорость и размер, как и на каком ПК это мерили и чего эти числа не говорят.

## Чем она рисует

- [GPUI](https://github.com/zed-industries/zed/tree/main/crates/gpui) — фреймворк интерфейса
  редактора кода Zed — рисует все окна программы видеокартой, через Direct3D 11, и все одним
  устройством: на ПК из замера у него уровень возможностей 11.1, а в запасе есть 11.0 и 10.1.
  Шейдеры компилируются при сборке программы, а не при её запуске.
- Каждое окно выводит кадры через собственную flip-цепочку буферов DXGI, а собирает окна вместе
  DirectComposition — поэтому оверлеи прозрачны попиксельно.
- Текст растеризует DirectWrite: глифы ложатся в атлас на видеокарте, и она рисует их оттуда — с
  ClearType в непрозрачных окнах и оттенками серого в прозрачных. Два шрифта интерфейса вшиты в exe.
- Процесс один, и доустанавливать ничего не нужно: один exe с вшитым C-рантаймом, без .NET, Visual
  C++ Redistributable и Chromium.
- Две вещи рисуют другие. Меню значка у часов — собственное меню Windows. Необязательное окно
  [входа на pathofexile.com](privacy.md#вход-на-pathofexilecom) показывает сайт во встроенном
  браузере Windows — Microsoft Edge WebView2. Он запускается, только когда вы нажимаете «Войти», а
  его процессы завершаются вместе с окном.

переднем плане. PoE2 Oracle, POE2 Currency Overlay, Exiled Exchange 2 и PoE Overlay II работали
одновременно, и каждая минута замера снимала все четыре. Sidekick в этом сеансе не участвовал.

обычно, а мы три минуты только снимали показания, ничего не нажимая. Каждая минута снимала все
четыре программы, так что игра у них была одна и та же.

### Проверки цены

Замер с 08:37 до 09:25 (UTC+3), со сборкой PoE2 Oracle на коммите 93296e4 — той, что была перед
5fc9b59. Проверили шесть предметов, каждый во всех четырёх программах.

Время отсчитано от нажатия клавиши по записи экрана с частотой 60 кадров в секунду, то есть с
точностью до кадра, ±17 мс. **Окно** — первый кадр, где видно окно программы. **Результат** —
последнее изменение в области окна, после которого 500 мс ничего не менялось.

| Предмет | PoE2 Oracle: окно / результат, мс | Самая быстрая из остальных по результату | Её окно / результат, мс |
|---|--:|---|--:|
| Валюта: стопка из 27 сфер усиления | 92 / **231** | POE2 Currency Overlay | 47 / 342 |
| Редкий шлем | 109 / **731** | POE2 Currency Overlay, с поиском | 46 / 792 |
| Редкое кольцо | 93 / 715 | POE2 Currency Overlay, с поиском | 46 / **669** |
| Редкий путевой камень (ур. 15) | 108 / 715 | POE2 Currency Overlay, с поиском | 48 / **686** |
| Неогранённый камень умения (ур. 18) | 108 / **217** | POE2 Currency Overlay | 46 / 280 |
| Волшебный самоцвет | 93 / 683 | POE2 Currency Overlay, с поиском | 47 / **638** |

- Валюту и камень PoE2 Oracle оценила без поиска по торговле и показала результат первой из четырёх
  программ: за 231 и 217 мс.
- Четыре предмета, которым нужен поиск по торговле, заняли у PoE2 Oracle 683–731 мс, а у POE2
  Currency Overlay — 638–792 мс; у POE2 Currency Overlay три из четырёх вышли быстрее. Большую часть
  этого времени занимает сайт торговли: по журналу PoE2 Oracle около 0,61 с из 0,64 с поиска уходит
  на ожидание двух ответов pathofexile.com (см. [Скорость и размер](#скорость-и-размер)).
- Окно POE2 Currency Overlay появлялось первым, через 46–48 мс, но в нём сначала был прошлый
  результат, пока не приходил новый.
- PoE Overlay II по сайту торговли не искал: через 451–659 мс (окно открывалось через 435–529 мс)
  он показывал свою оценочную стоимость с надёжностью «очень низкая» или «низкая», а для самоцвета
  не показал ничего.
- Exiled Exchange 2 открывал окно через 93–114 мс, а валюту и камень оценил за 917 и 980 мс. Его
  проверка по Ctrl+Y, которой здесь пользовались, по сайту торговли сама не ищет: для остальных
  четырёх предметов он показал фильтры и ждал «Поиск».
- Панель PoE2 Oracle проявляется плавно: её первый кадр был через 92–109 мс, а фильтры полностью
  нарисованы примерно к 200 мс.

Процессор на проверку — сколько процессорного времени процессы программы потратили за 13,3 секунды
от нажатия, за вычетом того, что они тратят за это время в простое. Память — «Память» диспетчера
задач до первой проверки и после последней.

| Программа | Процессов / потоков | Процессор на проверку, мс: медиана (разброс) | Память в диспетчере задач, МБ: до → после | Видеопамять выделенная, МБ |
|---|--:|--:|--:|--:|
| **PoE2 Oracle, коммит 93296e4** | **1 / 43** | **164** (89–223) | **35,1 → 47,7** | **84 → 130** |
| Exiled Exchange 2 | 4 / 100–103 | 154 (144–331) | 66,9 → 89,5 | 0 |
| PoE Overlay II + Overwolf | 9 / 318–326 | 1050 (602–1285) | 285,2 → 320,7 | 39 |
| POE2 Currency Overlay | 4 / 145–153 | 212 (148–385) | 41,8 → 106,3 | 71–72 |

- За шесть проверок память PoE2 Oracle выросла меньше всех: на 12,6 МБ, у Exiled Exchange 2 — на
  22,6 МБ, у PoE Overlay II — на 35,5 МБ, у POE2 Currency Overlay — на 64,5 МБ.
- Её выделенная видеопамять выросла с 84 до 130 МБ: после первой проверки окно панели остаётся.

PoE2 Oracle в игре не во всём лучше других. В контрольном замере, пока мышь стоит, у Exiled
Exchange 2 процессора чуть меньше: 0,081 % ядра против 0,088 %. На проверку Exiled Exchange 2 тоже
тратил чуть меньше процессора — 154 мс против 164 по медиане, — причём для четырёх предметов из
шести он по торговле не искал. Окно POE2 Currency Overlay появлялось первым, с прошлым результатом,
и три поиска по торговле из четырёх он закончил быстрее. А вокруг проверок цены выделенной
видеопамяти у PoE2 Oracle было больше всех четырёх: 84 МБ до них и 130 МБ после, у сборки перед
5fc9b59. В настоящей игре у сборки 786f69b было 68,1 МБ — меньше, чем 72,3 МБ у POE2 Currency
Overlay, но больше, чем у Exiled Exchange 2 и PoE Overlay II. См. [Оговорки](#оговорки).

- Память — в МБ по 1024 × 1024 байта, как в диспетчере задач. PoE Overlay II мерили через 2–3 и

- **Частные байты (commit)** — столбец «Выделенная память» на вкладке «Подробности»: память, которую
  Windows пообещала процессу в ОЗУ или в файле подкачки, трогал он её или нет.
- **Видеопамять выделенная** — память на самой видеокарте, **общая** — оперативная память, которую
  видеокарта использует для этого процесса.
- **ЦП в простое** — в процентах одного логического ядра: 100 % — одно ядро занято полностью. Ядер у
  этого ПК 24, поэтому в столбце «ЦП» диспетчера задач эти числа в 24 раза меньше: 110 % там
  выглядят как примерно 4,6 %.
- Строка PoE2 Oracle — медиана трёх окон замера, в 19:00, 19:01 и 19:03: программа работала одна
  рядом с игрой, через 3,7–8,2 минуты после запуска. В них было 39,6, 39,5 и 39,6 МБ и 0,128, 0,122
  и 0,116 % ядра; выделенной видеопамяти в первом окне было 71,8 МБ, в двух других — 40,1 МБ (см.
  [Оговорки](#оговорки)).
- В эти минуты PoE2 Oracle держала над игрой три окна: плашку опыта, её ⚙ и плашку карты, которая

## Оговорки

- **«Память» диспетчера задач и рабочий набор.** «Память», то есть частный рабочий набор, — это
  страницы процесса в ОЗУ, которые принадлежат только ему: самое честное одно число. Рабочий набор
  добавляет к ним страницы, общие с другими: DLL, отображённые файлы и память, которую процессы
  Chromium делят между собой. Если сложить рабочие наборы нескольких процессов, одни и те же страницы
  посчитаются по разу на каждый, и программа из многих процессов окажется тяжелее, чем есть; у
  PoE2 Oracle процесс один, и завышать нечего. Системные DLL и драйвер видеокарты, общие для всех
  программ, входят в рабочий набор каждого процесса и не входят ни в чью «Память». Частные байты —
  это обещанная, а не занятая память: у PoE2 Oracle при 162,6 МБ частных байтов в ОЗУ было 39,6 МБ.
- **Игру на переднем плане и в фоне друг с другом не сравнивают.** Числа в игре сняты 27 сентября с
  игрой на переднем плане, с игрой в фоне — 26 сентября, и из одних в другие они не переносятся.
  Особенно память: у POE2 Currency Overlay было 132,9 МБ, пока игра была в фоне, и 41,8 МБ в игре до
  первой проверки.
- **Три сборки в игре.** Проверки цены, а с ними память и видеопамять до и после них, мерили со
  сборкой на коммите 93296e4; контрольный замер — со сборкой 5fc9b59, в которой изменился
  наблюдатель экрана у оверлея опыта; настоящую игру — со сборкой 786f69b, следующим коммитом,
  который наблюдатель экрана не трогал.
- **Настоящая игра — один сеанс.** Игру владельца не повторить, и в другом сеансе числа будут
  другими. Все четыре программы снимались в одни и те же минуты, так что игра у них была одна.
  Остальным трём в каждой следующей минуте нужно было больше процессора, чем в предыдущей; по трём
  минутам не скажешь, продолжилось бы это или нет.
- **Время — с точностью до кадра: ±17 мс.** «Окно» — первый изменившийся кадр: у PoE2 Oracle это
  начало плавного появления панели. «Результат» у Exiled Exchange 2 для предметов, которым нужен
  поиск, — лишь его фильтры: поиска не было.
- **Процессор на проверку** включает и 13 секунд простоя, которые вычтены по замеру простоя; у
  PoE Overlay II это около 195 мс, поэтому разброс у него больше.
- **Память PoE2 Oracle до проверок** — у экземпляра, запущенного в 08:43: до первой проверки у него
  было 35,1 МБ. Экземпляр, запущенный в 08:12, в 08:38 показывал 14,4 МБ, потому что Windows урезала
  его рабочий набор, и его не сравнивают.
- **Видеопамять** — это счёт самой Windows по каждому процессу. Вокруг проверок цены выделенной
  видеопамяти у PoE2 Oracle было больше всех четырёх: 84 МБ до них и 130 МБ после, у сборки на
  коммите 93296e4. В настоящей игре у сборки 786f69b со скрытой панелью было 68,1 МБ — меньше, чем
  72,3 МБ у POE2 Currency Overlay; пока панель была открыта, журнал самой программы показывал
  83,7 МБ. Пока игра в фоне, у PoE2 Oracle видеопамяти больше, чем у Exiled Exchange 2 и
  PoE Overlay II, и меньше, чем у POE2 Currency Overlay и Sidekick; у сборки 15:32 было 70,5 МБ, у
  ранней — 159,6 МБ, больше, чем у всех. У сборки 18:30 в первом из трёх окон замера было 71,8 МБ:
  между 19:01:03 и 19:01:33, примерно через 4,5 минуты после запуска, видеопамять упала до 40,1 МБ
  и дальше не менялась. В журнале программы в это время ничего нет, а почему так вышло, не
  разбирали; в таблице — медиана трёх окон. По замеру видеопамять не раскладывали; по коду GPUI
  каждое окно держит видеопамять пропорционально своему размеру в пикселях, так что число растёт
  вместе с экраном, а у этого ПК 4K с масштабом 200 %. У Exiled Exchange 2 видеопамяти нет: он
  отключает аппаратное ускорение (`app.disableHardwareAcceleration()`) и рисует свой оверлей
  процессором. Внутриигровой оверлей Overwolf работает внутри процесса самой игры и в счёт
  PoE Overlay II не попал.
- **ЦП в простое, пока игра в фоне.** PoE2 Oracle брала 0,122 % одного ядра — медиану трёх окон, в
  которых было от 0,116 до 0,128 %. Это больше, чем у Exiled Exchange 2 (0,094 %), примерно как у
  POE2 Currency Overlay, чьи 0,119 % укладываются в этот разброс, и меньше, чем у Sidekick (0,145 %
  на странице настройки, 0,398 % в рабочем состоянии) и PoE Overlay II. Для этого 24-поточного
  процессора это 0,005 % целиком, и столбец «ЦП» диспетчера задач показывает 0. Плашки PoE2 Oracle
  всё время видны над игрой, а остальные программы в это время ничего поверх неё не показывали. По
  потокам в двух из трёх окон примерно треть этого времени ушла на потоки драйвера видеокарты,
  треть — на пул потоков Windows, где GPUI выполняет свои таймеры и фоновую работу, четверть — на
  поток интерфейса и десятая часть — на поток кадровой синхронизации GPUI. Сборка 15:32 брала
  0,20 %, а когда игра была закрыта и плашки спрятаны, — 0,14 %; ранняя сборка — 0,70–0,76 %.
- **Что мерили, пока игра в фоне: простой.** Оверлеи в тех сеансах никто не открывал и цены не
  проверял; проверки цены мерили в игре. POE2 Currency Overlay был открыт на вкладке «Проверка цены»,
  как её сохранили его настройки; на вкладке «Валюта» он раз в 6 секунд запрашивает живые курсы, и
  это не мерили.
- **В каком состоянии были программы.** Exiled Exchange 2 окон не открывал: он ждёт в трее и
  показывает оверлей по <kbd>Shift</kbd>+<kbd>Space</kbd>. Sidekick работал на настройках прошлой
  установки, лига в которых уже закончилась. При первом запуске он открыл окно настройки с просьбой
  выбрать лигу и ждал в нём — это строка «ждёт на странице настройки»: так его увидит любой, у кого в
  настройках лига прошлого сезона. С текущей лигой в настройках следующий запуск прошёл всю
  инициализацию за 12 секунд без окон (в тех настройках включён тихий старт) — это строка «готов к
  работе», и сравнивать надо с ней. PoE Overlay II, запущенный ярлыком, сам открыл главное окно на
  втором мониторе, не забирая фокус: персонаж, сводка сессии, тайник, а рядом два анимированных
  рекламных баннера, товары на которых сменились между снимками с разницей в 45 секунд, и два
  предложения перейти на Premium, чтобы убрать рекламу. Пока это окно открыто, браузер Overwolf
  постоянно его перерисовывает: его GPU-процесс занимал 92–99 % ядра, а процесс страницы — ещё
  10–13 %. Потом окно свернули его же командой «Свернуть» и измерили снова. Закрыть окно, не закрывая
  программу, не пробовали. POE2 Currency Overlay при запуске показал заставку, которой к 30-й
  секунде уже не было, а окна первого запуска не было: обучение в тех настройках уже пройдено. Над
  игрой он держит одно окно — поверх всех остальных, пропускающее щелчки и полностью прозрачное: его
  не видно, пока горячая клавиша его не проявит. У остальных программ рекламы не было; в окне
  POE2 Currency Overlay есть ссылка на страницу доната Ko-fi.
- **Session Recap у PoE Overlay II, в игре.** Когда игра теряла фокус, PoE Overlay II открывал

- **Три сборки, пока игра в фоне.** Сайт сравнивает сборку 18:30 с программами, которые мерили рядом

- **Состояние игры и плашки важны.** Когда игру закрывает другое окно, PoE2 Oracle прячет плашки, и

  карты появляется, только когда после входа в игру уже была карта, и сборку 18:30 мерили с ней: над
  игрой было три окна, а у сборок до неё — два. Если это и сказалось, то не в пользу сборки 18:30.

- **Первые минуты против часов.** Пока игра в фоне, остальные программы мерили через 1,5–8,5 минуты
