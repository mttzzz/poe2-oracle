# Обновления и удаление

## Обновления

PoE2 Oracle обновляется с [oracle.pushka.biz](https://oracle.pushka.biz/ru/) — сайта самой
программы. Без вашего щелчка ничего не устанавливается.

- Если включено «Проверять обновления» (по умолчанию включено), через 30 секунд после запуска
  программа спрашивает у oracle.pushka.biz последний выпуск. Всплывающих окон нет: когда есть новая
  версия, пункт обновления в меню значка меняется на «Установить версию X.Y.Z».
- Проверить самому — пункт «Проверить обновления» в меню значка. Сначала он покажет «Проверка
  обновлений…», потом «Установлена последняя версия» или «Не удалось проверить обновления» (щёлкните
  ещё раз, чтобы повторить).
- Чтобы обновиться, нажмите «Установить версию X.Y.Z». Пока PoE2 Oracle скачивает файл
  `SHA256SUMS` выпуска, проверяет его подпись Ed25519 ключом, встроенным в программу, а затем
  скачивает установщик и сверяет его контрольную сумму SHA-256 с `SHA256SUMS`, в меню написано
  «Загрузка версии X.Y.Z…». Ключ подписи хранится только там, где собираются выпуски, поэтому ни
  oracle.pushka.biz, ни кто-либо по пути не подсунет свой установщик. Затем программа
  закрывается, установщик тихо ставит новую версию, и через несколько секунд она запускается сама.
  Настройки и автозапуск остаются как были.
- Если загрузка или проверка не удалась, пункт покажет «Ошибка обновления — повторить (X.Y.Z)» —
  щёлкните, чтобы попробовать снова. Тогда ничего не запускается: при неверной подписи установщик
  даже не скачивается, а файл, не совпавший с контрольной суммой, удаляется.

Обновиться можно и вручную: скачайте новый установщик с
[oracle.pushka.biz](https://oracle.pushka.biz/ru/) и запустите его. Он встанет поверх старой
версии, в ту же папку, с сохранением настроек.

Скачанные установщики лежат в `%LOCALAPPDATA%\poe2-oracle\cache\updates`; следующее обновление
удаляет старый.

## Удаление

1. Откройте в Windows **Параметры → Приложения → Установленные приложения** (в Windows 10 —
   **Приложения и возможности**).
2. Найдите **PoE2 Oracle** (издатель mttzzz) и выберите **Удалить**.
3. Если PoE2 Oracle запущен, программа удаления закроет его.

Удаляются программа, её ярлык в меню «Пуск», автозапуск и сохранённый вход на pathofexile.com.
Настройки и скачанные данные остаются для переустановки, если не отметить пункт **«Настройки и
кэш»**: «Удалить также настройки и загруженные данные о ценах. Оставьте без отметки, чтобы сохранить
их для переустановки.» С этой отметкой удаляются папки `%APPDATA%\poe2-oracle` и
`%LOCALAPPDATA%\poe2-oracle` — вместе с логами и сохранёнными текстами предметов.

Позже их можно убрать и вручную: достаточно удалить эти две папки.
